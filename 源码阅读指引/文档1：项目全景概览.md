# 项目全景概览

**目标读者**：初次接触项目的新人。

## 项目一句话简介
**Pixelle-Video** 是一个基于 AI 驱动的一站式视频生成平台，支持从文本到语音（TTS）、图像生成、文案创作直到最终视频渲染的端到端全自动管线。

## 核心技术栈
- **后端语言与框架**：Python 3.11+ / FastAPI (提供高性能异步接口) / Uvicorn (ASGI服务器)
- **前端框架**：Streamlit (用于快速构建多页面 Web 交互 UI)
- **AI 与音视频处理**：
  - `openai`: LLM 交互与文案/提示词生成
  - `comfykit`: 图像生成（封装 ComfyUI 工作流）
  - `edge-tts`: 文本转语音引擎
  - `ffmpeg-python` / `moviepy`: 视频合成、音频混流与剪辑
- **核心工具包**：`pydantic` (数据校验)、`loguru` (优雅的日志管理)、`uv` (极速包管理)

## 快速启动
基于项目根目录的 `pyproject.toml` 和代码结构，你可以通过以下命令快速拉起服务：
```bash
# 1. 安装依赖 (推荐使用 uv)
uv pip install -e .[dev]

# 2. 启动 FastAPI 后端服务
uv run python api/app.py --host 0.0.0.0 --port 8000 --reload

# 3. 启动 Streamlit 前端 Web UI (开一个新的终端)
uv run streamlit run web/app.py
```
