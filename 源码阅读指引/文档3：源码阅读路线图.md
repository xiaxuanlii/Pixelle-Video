# 源码阅读路线图

**目标读者**：正在学习源码的开发者。

## 入口点定位
- **API 后端入口**：`api/app.py` (FastAPI 的组装和启停生命周期注册点)
- **Web 前端入口**：`web/app.py` (Streamlit 的多页面导航配置点)
- **CLI 命令行入口**：`pixelle_video.cli:main` 

## 阅读顺序建议
1. **先看配置文件与数据模型**：了解项目能做什么。阅读 `api/schemas/` 和 `pixelle_video/models/`，特别是 `Storyboard`（分镜模型）和 `PipelineContext`（上下文数据）。
2. **再看核心管线编排**：阅读 `pixelle_video/pipelines/standard.py`。不用深究细节，先看清它是如何一步步把文字变成视频的。
3. **深入基础设施实现**：挑选一个你感兴趣的节点，如进入 `pixelle_video/services/video.py` 或 `comfy_base_service.py` 探究底层是如何用 FFmpeg/ComfyUI 干活的。
4. **最后看接口与任务分发**：阅读 `api/routers/video.py` 和 `api/tasks/manager.py`，了解长耗时任务是如何在后台异步运行并反馈进度的。

## 关键类/函数清单
1. **`StandardPipeline`** (位于 `pixelle_video/pipelines/standard.py`)
   - **必读原因**：该类完整诠释了“剧本撰写 -> 画面规划 -> 分镜生成 -> 素材渲染 -> 视频后处理”的全生命周期。
2. **`lifespan` 协程函数** (位于 `api/app.py`)
   - **必读原因**：应用启动时的资源初始化中心，理解 `task_manager` 等单例服务是如何挂载的。
3. **`VideoService.render_video`** (推测位于 `services/video.py` 等文件中)
   - **必读原因**：音视频复合逻辑最密集的地方，展示了如何用 Python 精准控制 FFmpeg 过滤图（Filtergraph）和转场。
